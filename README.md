# Бот-напоминатель

Установка: `python -m pip install -r requirements.txt`

1. Вставьте токен от @BotFather в `config.py`.
2. Запустите `python bot.py`.

Задачи сохраняются в `tasks.json` рядом с ботом. Для каждой задачи доступны кнопки: готово, отложить на 10 минут, включить/выключить автонапоминание, настроить интервал, изменить срок и удалить. Интервал индивидуальный (5–10080 минут). Тихие часы: 22:00–08:00.

Подключение использует системный HTTPS-прокси, затем HTTP-прокси, а если прокси не настроен — прямое соединение.
